# Проверка демонстрации — 31 октября 2026

Собрана цель `PortalCraneEditor Win64 Development` для установленного Unreal Engine 5.7. Использованы MSVC 14.44.35229, Windows SDK 10.0.26100.0 и .NET Framework 4.8 SDK.

## Автоматические проверки

`Tools/Test.ps1` (30 октября): **2 успешных теста, 0 предупреждений, 0 ошибок**. После этого менялась только отрисовка шкалы; финальная редакторская сборка 31 октября завершилась успешно.

- `PortalCrane.Telemetry.Thresholds`: границы нагрузки и ветра, одновременные предупреждения, подтверждение и восстановление нормального состояния.
- `PortalCrane.Telemetry.Controls`: автоцикл, пауза, ручной ввод, аварийный стоп, сброс, ограничение диапазонов, отклонение бесконечных значений, предел журнала в 64 события.

Полный отчёт находится в `Saved/TestReport/index.json`. Команда воспроизведения: `powershell -ExecutionPolicy Bypass -File .\Tools\Test.ps1`.

## Проверка работающего интерфейса

- Демонстрация запущена отдельным окном через `Tools/Run.ps1`.
- Снимок UE подтверждает отображение русских надписей, схемы, показаний и регуляторов при размере 1280 × 720.
- Реальным вводом мыши включён сценарий перегрузки: масса 30 т, красная тревога и запись в журнале.
- Кнопка экспорта создала CSV в `Saved/CraneLogs`. Проверены две колонки, кодировка UTF-8 и сохранность кириллицы в событии перегрузки.
- 31 октября проверена финальная отрисовка шкалы: при расчётной загрузке 46,5% цветная часть на снимке UE занимает 103 из 221 пикселя (46,6%, погрешность округления). Фон и заполнение отрисовываются напрямую, без стандартной текстуры прогресс-бара. Актуальный снимок: `Docs/Preview.png`.

Для автономного запуска проект использует файловый кэш `DerivedDataCache` в своей папке. Это устранило обнаруженную в данном окружении недоступность локального HTTP-сервиса Zen.

Проверки относятся к учебной визуализации. Подключение к оборудованию и работа с реальными грузовыми характеристиками не реализованы.
